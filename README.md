# 線上認同能否替代線下認同？臺灣青少年線上與線下自我認同組合與身心狀態

本專案為「臺灣青少年線上與線下自我認同組合與身心狀態」研究的完整資料處理與分析程式。研究使用「臺灣數位世代青少年的成長歷程追蹤研究」（TIGPS）第一波與第二波學生問卷，依線上與線下自我認同的高低將青少年分為四種類型，探討兩種認同的組合與六項身心狀態指標之間的關聯，並檢驗線上認同能否彌補線下認同的不足。

## 研究問題

1. 線上與線下自我認同的不同組合（雙高型、線上優勢型、線下優勢型、雙低型），其身心狀態是否不同？
2. 線下自我認同是否調節線上自我認同與身心狀態之間的關聯？
3. 延伸分析：社群媒體使用程度與線上、線下自我認同之間有何關聯？

## 分析流程

所有程式皆在專案根目錄執行，例如 `python scripts/01_merge_family_vars.py`。

```
            ┌───────────────── 資料整合與清理（依序執行）─────────────────┐
原始資料 → 01 跨波合併 → 02 資料清理 → 03 自我認同分數與四象限分類
                                                │
                     ┌──────────────────────────┼─────────────────────────────┐
                     ▼                          ▼                             ▼
            03a 四象限分布圖        04 / 04b 組間差異檢定        05 主要模型、05c 延伸模型
                                                                              │
                                                                              ▼
                                                                    06 報告用 LaTeX 表格
```

01 → 02 → 03 必須依序執行；之後的分析程式皆讀取 03 產生的分析資料檔，彼此獨立。畫圖與表格的程式（`04b_bar_chart.py`、`05_marginal_effects_panel.py`、`05c_coef_forest_plot.py`、`06_report_tables.py`）只讀取 `results/` 中的 CSV，需在對應的分析程式之後執行。

| 程式 | 功能 |
|---|---|
| `01_merge_family_vars.py` | 以學生識別碼將第一波的家庭背景變數合併至第二波全體樣本，並檢查配對情形 |
| `02_clean_data.py` | 將問卷缺失代碼轉為缺失值，清理自我認同、背景控制變數、身心狀態指標與社群媒體使用時數題項 |
| `03_quadrant.py` | 計算線上、線下自我認同分數，排除題目未完整作答者，依中位數分為四種類型 |
| `03a_visualization.py` | 繪製四象限分布熱力圖 |
| `04_group_diff_6outcomes.py` | 六項身心狀態指標的四象限組間差異（ANOVA、Kruskal-Wallis、效果量、FDR 校正） |
| `04b_extension_social_media_behavior.py` | 四象限在兩項社群媒體使用時數上的差異 |
| `04b_bar_chart.py` | 上述結果的長條圖 |
| `05_all_models.py` | 主要模型：四象限分類模型、連續分數交互作用模型、組間兩兩比較、邊際效果分析 |
| `05_marginal_effects_panel.py` | 線上自我認同邊際效果的 2×3 小圖 |
| `05c_usage_on_identity.py` | 延伸模型：社群媒體使用程度與線上、線下自我認同 |
| `05c_coef_forest_plot.py` | 延伸模型的係數森林圖 |
| `05c_marginal_effects_plot.py` | 延伸模型的平均預測曲線 |
| `05c_nonlinearity_check.py` | 延伸模型的線性假設檢查（二次項與分組調整後平均） |
| `06_report_tables.py` | 由結果 CSV 產生報告第 3 節的 LaTeX 表格 |

每支程式開頭的說明列有詳細的輸入與輸出檔案。

## 分析方法摘要

- **樣本**：第二波學生問卷中，線上與線下自我認同六題皆有效回答者（N = 8,855）；各模型再依所用變數排除缺失（complete case per model）。
- **四象限分類**：依線上、線下自我認同分數的中位數，分為雙高型、線上優勢型、線下優勢型、雙低型。
- **主要模型**：OLS 迴歸，採 HC3 穩健標準誤；模型 A 以雙低型為對照組，模型 B 使用平均數中心化的連續分數及其交互作用項。皆估計未納入與納入背景控制變數兩種版本，背景控制變數以類別變數納入。
- **多重比較**：依六項身心狀態指標以 Benjamini-Hochberg 法進行 FDR 校正。
- **限制**：核心變數皆來自第二波同一時間點，結果僅代表關聯，不代表因果。
